=== ruflo policy --help

ruflo policy
Agentic policy engine — evaluate actions, manage rules/approvals, and verify the decision ledger (ADR-324)

OPTIONS:
      --mode                Policy mode: legacy | observe | enforce
      --project-root        Project root containing .claude-flow/policy
      --establish-anchor    verify: explicitly anchor a ledger that has receipts but no anchor (interactive, logged with user and time)

EXAMPLES:
  $ ruflo policy status
    Show policy mode and ledger health
  $ ruflo policy init --mode observe
    Migrate an existing install without blocking legacy actions
  $ ruflo policy budget set '{"id":"daily-model","action":"model.call","maxCostUsd":10,"periodMs":86400000}'
    Set an atomic policy budget ceiling
  $ ruflo policy evaluate '{"identity":{"id":"agent-1","type":"agent"},"action":{"type":"deploy","environment":"production"}}'
    Evaluate an action and write a decision receipt

SUBCOMMANDS:

  $ claude-flow guidance optimize
    Analyze and optimize CLAUDE.md
  $ claude-flow guidance ab-test

=== ruflo memory --help

ruflo memory
Memory management commands

SUBCOMMANDS:
  init            Initialize memory database with sql.js (WASM SQLite) - includes vector embeddings, pattern learning, temporal decay
  store           Store data in memory
  retrieve        Retrieve data from memory (get)
  search          Search memory with semantic/vector search
  list            List memory entries (ls)
  delete          Delete a memory entry from the default store and its AgentDB mirror (use --path to select one store) (rm)
  purge           Permanently delete a namespace from the default store and its AgentDB mirror (use --path to select one store)
  stats           Show memory statistics
  configure       Configure memory backend (config)
  cleanup         Clean up stale and expired memory entries
  compress        Compress and optimize memory storage
  export          Export memory to file
  import          Import memory from file
  distill         Memory distillation (ADR-174): mine memory_entries into reasoning_patterns/episodes/causal_edges
  backup          Snapshot active project memory stores — WAL-safe, rotated, optional GCS offsite
  classify        Classify a query into episodic/semantic/procedural intent (SCM router, dream-cycle #2760)
  select-operator Pick the highest-value consolidation operator that fits a budget (OAS, dream-cycle #2763)

EXAMPLES:
  $ claude-flow memory store -k "key" -v "value"
    Store data
  $ claude-flow memory search -q "auth patterns"
    Search memory
  $ claude-flow memory stats
    Show statistics

=== ruflo hooks --help

ruflo hooks
Self-learning hooks system for intelligent workflow automation

SUBCOMMANDS:
  pre-edit        Get context and agent suggestions before editing a file
  post-edit       Record editing outcome for learning
  pre-command     Assess risk before executing a command
  post-command    Record command execution outcome
  pre-task        Record task start and get agent suggestions
  post-task       Record task completion for learning
  session-end     End current session and persist state
  session-restore Restore a previous session
  route           Route task to optimal agent using learned patterns
  explain         Explain routing decision with transparency
  pretrain        Bootstrap intelligence from repository (4-step pipeline + embeddings)
  build-agents    Generate optimized agent configs from pretrain data
  metrics         View learning metrics dashboard
  transfer        Transfer patterns and plugins via IPFS-based decentralized registry
  list            List all registered hooks (ls)
  intelligence    RuVector intelligence system (SONA, MoE, HNSW 150x faster)
  notify          Send a notification message (logged to session)
  worker          Background worker management (12 workers for analysis/optimization)
  progress        Check V3 implementation progress via hooks
  statusline      Generate dynamic statusline with V3 progress and system status
  coverage-route  Route task to agents based on test coverage gaps (ruvector integration)
  coverage-suggest Suggest coverage improvements for a path (ruvector integration)
  coverage-gaps   List all coverage gaps with priority scoring and agent assignments
  token-optimize  Token optimization via agentic-flow Agent Booster integration
  model-route     Route task to optimal Claude model (haiku/sonnet/opus) based on complexity
  model-outcome   Record model routing outcome for learning
  model-stats     View model routing statistics and learning metrics
  route-task      (DEPRECATED: Use "route" instead) Route task to optimal agent
  session-start   (DEPRECATED: Use "session-restore" instead) Start/restore session
  pre-bash        (ALIAS) Same as pre-command
  post-bash       (ALIAS) Same as post-command
  teammate-idle   Handle idle teammate in Agent Teams - auto-assign tasks or notify lead
  task-completed  Handle task completion in Agent Teams - train patterns and notify lead
  refresh-funnel  Best-effort background refresh of the funnel message cache (internal — see hook-handler.cjs session-restore)
  refresh-advisor Best-effort background refresh of the co-pilot advisor tip (internal — see hook-handler.cjs session-restore; ADR-316)

EXAMPLES:
  $ claude-flow hooks pre-edit -f src/utils.ts
    Get context before editing
  $ claude-flow hooks route -t "Fix authentication bug"
    Route task to optimal agent
  $ claude-flow hooks pretrain
    Bootstrap intelligence from repository
  $ claude-flow hooks metrics --v3-dashboard
    View V3 performance metrics
