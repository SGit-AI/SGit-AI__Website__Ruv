- `npm i --ignore-scripts` leaves better-sqlite3 unbuilt: Ruflo falls back to sql.js and WARNS "persistence is not guaranteed". Run `npm ci` WITH scripts (or `npm rebuild better-sqlite3`) before any memory POC.
- Ruflo auto-starts a background daemon on some commands ("Started Ruflo background daemon ... stop: ruflo daemon stop"). No switch to disable it was found; always run `npx ruflo daemon stop` in a cleanup step (CI and local).
- `ruflo memory export` returned `count: 0` after a successful `memory store` (export reads a different store than store writes to: .claude/memory.db vs .swarm/memory.db). `memory import` failed with `policy-anchor-log-missing` on a fresh project. WORKAROUND THAT WORKED: copy the DB files (`.swarm/memory.db`, `.swarm/agentdb-memory.db`, `.claude/memory.db`, `ruvector.db`) into a fresh folder: `memory retrieve` / `memory list` return the entry. POC2 therefore vaults the DB files (binary) plus a readable `memory list` dump.
- `ruflo policy init|rule|budget` refuse without an interactive TTY ("policy administration requires an interactive local terminal"). Do not work around this; POC1 uses the library engine (`AgenticPolicyEngine` from `@claude-flow/security/policy/index`), an in-memory engine of our own, which is the documented library surface.
