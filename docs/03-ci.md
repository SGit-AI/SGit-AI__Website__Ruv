# CI design (.github/workflows/pocs.yml)
- `build`: npm ci (with install scripts) -> `abp:gate` (fails on gaps) -> poc1 -> poc3 -> poc4:build -> ruflo daemon stop -> upload `out/`.
- `publish-to-vault`: runs in a protected GitHub **environment** `vault` (a named human approves: that IS the ABP's `approval` row for `create.record.world`) -> writes `out/` to `ruv-pocs-public` under `runs/<run_id>/` -> `sgit publish --visibility public --yes`.
- `poc2-write` (matrix coder, tester; serial) -> `poc2-read` on a fresh runner: proves memory survives ephemeral compute.
- Secrets: `SGIT_TOKEN`, `SGIT_VAULT_KEY_PUBLIC`, `SGIT_VAULT_KEY_MEMORY`; masked; keys passed via stdin to `sgit clone`.
- Optional later: run the gate on every PR that touches `abp/` (policy changes reviewed like code); attach `report.md` to the job summary (`>> $GITHUB_STEP_SUMMARY`).
