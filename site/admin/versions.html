Release history

The site version (v0.1.5, shown in the nav of every page) increments on every release, and each release is one push to the dev branch of SGit-AI/SGit-AI__Website__Ruv. The git log is the authoritative audit trail; this page is the human-readable index of it. The same convention as sgit.ai and newsroom.sgit.ai.
