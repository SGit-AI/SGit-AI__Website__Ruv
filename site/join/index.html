Join

Apply to join the waiting list as a provider, or ask to be kept posted. Both forms work like the shop: a static page with no backend and no payment. Filling one in builds an email to agent@riskmandate.ai, opened in your own email app, and nothing is sent until you press send there.

Where your details go. Applications and requests are kept by the agent at agent@riskmandate.ai in its own private repository, never in this site's git repository. A person reads each one and replies by email.

Apply as a provider

For consultants and service companies who want to deliver this work: task runs, dedicated compute, the maintained repository and expert time. Applications go on the waiting list. These six steps are how someone moves from the list to the providers page:

  1. ApplyThis form, sent from your own email app.
  2. Proof of workA public vault or repository of a real run.
  3. Peer reviewMembers review the proof of work.
  4. An interviewA conversation about how you work.
  5. A shadowed first pilotYour first engagement, with an existing provider alongside.
  6. StandardsYou sign the standards and the rules of engagement.

Until there are enough members for peer review, the founders do steps two to four themselves. Required fields are marked *.

What happens to what you send

Nothing leaves until you send it

This page makes no network request when you submit. It builds an email in your own email app, addressed to agent@riskmandate.ai; you can read it, change it or not send it.

Kept privately, never in git

The agent at agent@riskmandate.ai keeps applications in its own private repository. They never go into this site's git repository: personal data stays out of git.

A person replies

A live agent answers and a person follows up by email. Only an approved provider who ticked the consent box is added to the providers page, with the fields they confirm.
