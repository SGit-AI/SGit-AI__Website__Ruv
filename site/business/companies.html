The continuum

Start where it is cheap to learn. Move along as the demand is proven. Each step uses the same runner, the same behaviour policies, the same vaults.

  1. Resell runs

    Buy task runs on shared infrastructure and sell them on, with your expertise around them. Nothing to deploy.

  2. White label

    Your brand on the offering and the deliverables. We run the hives behind you; you hand your clients their run vaults.

  3. Your own deployment

    Dedicated compute, one machine per task, with the vault created inside that environment (designed, not built yet). Then the maintained repository: the code that runs this, kept current, with your UI, branding and setup, on Claude Code, on AWS, or anywhere you choose.

Not automated end to end yet. A person on our side starts each run and watches it to the end. The runs on this site used a local vault server on the machine that ran the hive, so their timings are local numbers; the workers were Claude Code subagents, with Ruflo holding the queen, the roles, the tasks and the broadcasts. Dedicated compute and the materials sandbox for customer uploads are not built yet, and SG Compute is not connected to runs: when we reply to an order we say what we can do today.
